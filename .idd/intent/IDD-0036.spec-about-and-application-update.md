# IDD-0036.spec-about-and-application-update

## Intent

CSharpGit показывает собственную release version в `About CSharpGit`, автоматически
проверяет latest stable GitHub Release и, когда приложение действительно установлено
через поддерживаемый Homebrew Cask на macOS, позволяет безопасно обновить и
перезапустить приложение без отдельного distribution channel.

## Behavior

- `About CSharpGit…` доступен как из repository workspace overflow-menu, так и
  со стартового экрана.
- About открывается немедленно и показывает текущую version до завершения сети.
- Latest version определяется через GitHub endpoint
  `GET /repos/DimonSmart/CSharpGit/releases/latest`.
- Version сравнивается как `MAJOR.MINOR.PATCH`, а не как строка.
- Stable release новее текущей версии показывает `Open release page`; URL
  используется непосредственно из GitHub response.
- Ошибка сети, timeout или malformed response остаются локальным состоянием
  About и не нарушают работу приложения.
- `Update now` доступен только на macOS, когда:
  - найден executable Homebrew;
  - CSharpGit установлен как `dimonsmart/csharpgit/csharpgit`;
  - текущий process запущен из `/Applications/CSharpGit.app/Contents/MacOS/`.
- Manual ZIP, debug build, нестандартный `.app`, отсутствие Homebrew или другая
  CSharpGit installation не получают кнопку автоматической установки.
- Windows и Linux получают About, version check и release-page navigation без
  автоматической установки.

## Homebrew Update Contract

- Перед изменением package выполняется `brew update`.
- Затем `brew info --cask --json=v2 dimonsmart/csharpgit/csharpgit` должен
  подтвердить, что Cask version не старее GitHub Release version.
- Publication lag GitHub Release -> Homebrew Cask не должен устанавливать старую
  версию; пользователь получает понятное сообщение и остаётся в текущем процессе.
- Изменение package выполняется только targeted command:
  `brew upgrade --cask --no-quit --appdir=/Applications dimonsmart/csharpgit/csharpgit`.
- После начала `brew upgrade` cancellation отключается; работающий Homebrew
  process не убивается.
- После upgrade `/Applications/CSharpGit.app/Contents/Info.plist` должен
  подтвердить `CFBundleShortVersionString >= expectedVersion`.
- После version verification quarantine удаляется через `/usr/bin/xattr`; если
  quarantine снять нельзя, новый экземпляр автоматически не запускается.
- Relaunch выполняется через `/usr/bin/open -n /Applications/CSharpGit.app`.
- Старый process завершает существующий application lifecycle только после
  успешного relaunch.

## Safe Restart

- До начала package modification применяются существующие close/state guards.
- Active history rewrite и repository maintenance запрещают начало update.
- Unsaved commit message использует существующий confirmation flow.
- После подтверждения и успешного relaunch повторный close confirmation не
  показывается.
- Пока update выполняется, обычное закрытие main window не обходит updater flow.
- Ошибка update не завершает текущий CSharpGit process.

## Durable Architecture And Constraints

- About оркестрирует UI, но не содержит HTTP, Homebrew или process execution
  semantics.
- GitHub check, process execution, macOS Homebrew installer и system URI launcher
  находятся за application abstractions.
- Homebrew commands запускаются напрямую через argument list, без `sh -c`.
- GitHub check не требует authentication и имеет короткий timeout.
- Existing GitHub Release + Homebrew Cask pipeline остаётся единственным
  distribution mechanism для self-update.
- Windows/Linux updater можно добавить позднее без изменения About contract.

## Acceptance Criteria

- About показывает текущую release version и состояния checking/up-to-date/update
  available/unavailable.
- New stable release всегда можно открыть в browser.
- Поддерживаемая Homebrew installation на macOS получает `Update now`.
- Unsupported installation не получает опасную automatic-update action.
- Publication lag, malformed Homebrew metadata, failed upgrade, failed version
  verification, quarantine failure и relaunch failure не закрывают текущий process.
- Successful update проверяет installed version, снимает quarantine, запускает
  новый экземпляр и выполняет safe restart старого.
- Version/check/updater behavior покрыт unit/contract tests.
