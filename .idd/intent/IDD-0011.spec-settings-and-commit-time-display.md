# IDD-0011.spec-settings-and-commit-time-display

## Intent

CSharpGit предоставляет расширяемое отдельное окно глобальных настроек и единый
способ отображения времени коммитов, чтобы пользователь мог выбрать привычное
представление без изменения Git semantics или порядка истории.

## Behavior

- Settings открываются в отдельном desktop window.
- Слева находится вертикальная навигация по разделам настроек; первая страница —
  `General`. Архитектура допускает добавление новых страниц без перестройки окна.
- На первой странице пока настраивается только `Commit time display`.
- Настройка глобальна для приложения, сохраняется между запусками и применяется
  сразу ко всем отображениям времени коммитов.
- Поддерживаются только три основных режима:
  - `Smart` — режим по умолчанию и рекомендуемый: коммиты младше 30 дней
    отображаются относительным временем; более старые — календарной датой, без
    года для текущего года и с годом для предыдущих лет.
  - `Relative` — всегда показывает возраст (`3 hours ago`, `12 days ago`,
    `8 months ago`).
  - `Absolute` — всегда показывает локальные дату и время в компактном стабильном
    формате `yyyy-MM-dd HH:mm`.
- Hover над временем всегда показывает точные локальные дату, время, секунды и
  UTC offset независимо от выбранного режима.
- Relative/Smart representation обновляется во время работы приложения, чтобы
  видимое значение не оставалось устаревшим надолго.
- Источником времени остается `CommitHistoryItem.AuthoredAt`; эта настройка не
  меняет Git timestamp semantics.
- Сортировка, фильтрация и другие операции работают по исходному timestamp, а не
  по отформатированной строке.
- Presentation использует единый reusable component/formatter для commit time,
  а не дублирует форматирование в отдельных views.

## Durable Architecture And Constraints

- Значение режима представлено явным application-level enum и доступно через
  settings service boundary.
- Persistence реализована вне Git/domain logic; поврежденный или недоступный
  settings file не мешает запуску и приводит к безопасному default `Smart`.
- Изменение настройки публикуется текущим views сразу; сохранение выполняется в
  пользовательскую application-data директорию.
- UI использует стандартные Uno/Fluent controls и остается общим для Windows,
  macOS и других Skia Desktop targets.

## Non-Goals

- Настройки на уровне отдельного repository.
- Пользовательский формат даты/времени.
- Изменение AuthorDate/CommitterDate semantics.
- Синхронизация настроек между устройствами.

## Acceptance Criteria

- `Settings…` из главного окна открывает отдельное окно с вертикальной навигацией
  слева и страницей `General`.
- В `General` доступны Smart, Relative и Absolute; Smart выбран при первом
  запуске.
- Переключение режима сразу изменяет видимые времена в history и commit details.
- После перезапуска выбранный режим восстанавливается.
- Tooltip каждого commit time показывает точное local timestamp с offset.
- Smart использует relative до 30 дней и calendar date после порога.
- Relative корректно формирует основные единицы времени, включая future clock
  skew, а Absolute имеет стабильный компактный формат.

## Verification

- Unit tests фиксируют поведение formatter для Smart, Relative, Absolute и
  future clock skew.
- Desktop build проверяет XAML и reusable commit-time control вместе с основным
  приложением.
- Ручная проверка подтверждает отдельное окно Settings, immediate update,
  persistence после restart и exact tooltip.
