# IDD-0026.spec-commit-metadata-copy

## Intent

Commit details let users copy exact commit metadata without selecting text or starting extra Git work.

## Related Specifications

- IDD-0004
- IDD-0010
- IDD-0019

## Behavior

- The Commit surface has compact copy actions beside the full commit message and full commit hash.
- Each parent hash has its own copy action, including merge commits with multiple parents.
- Root commits show `—` for parents and no parent copy action.
- Clipboard content is the exact full value, never `ShortHash` or another shortened display form.
- Successful copy gives brief non-modal visual feedback and uses tooltip/accessibility names.

## Durable Architecture And Constraints

- Copying uses the already-loaded `SelectedHistoryRow.Commit` data and existing presentation clipboard infrastructure.
- Metadata copy actions run no Git process and add no application/domain workflow.

## Acceptance Criteria

- Message Copy copies the full message.
- Commit hash Copy copies the full SHA.
- Parent Copy copies the selected individual parent SHA.
- Root commit shows `—` and no parent Copy.
- Copy success is indicated briefly without a dialog or InfoBar.
- Existing history selection remains zero-Git-process metadata navigation.

## Verification

- UI contract tests assert message/hash/parent bindings, full-value semantics, root-parent empty state, and non-modal feedback.
